# Notera · 乐理练习室

面向吉他初学者的中文乐理练习应用，通过音程推算、指板定位与和弦对应建立熟练度。

技术栈：**React 19 + TypeScript + Vite**，使用 **pnpm** 管理依赖、**Vitest + Testing Library** 验证算法和交互。

## 本地运行

需要 Node.js 22.12+（当前已在 Node.js 24 上验证）和 pnpm 10。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://127.0.0.1:5173 。停止运行按 Ctrl+C。Vite 支持开发热更新。

服务器默认监听所有网络接口。同一局域网的其他设备可打开 `http://这台电脑的局域网IP:5173`，使用启动输出中的 Network 地址；其他设备上的 `127.0.0.1` 或 `localhost` 指向设备自身。电脑需保持服务运行，设备需处于可互通的同一网络；如果仍无法连接，请检查系统防火墙是否允许 Node.js 接受传入连接，以及路由器是否开启访客网络或设备隔离。生产构建预览使用相同方式访问，端口为 `4173`。

项目锁定 `packageManager: pnpm@10.23.0`，提交 `pnpm-lock.yaml`，请使用 pnpm 安装依赖。

## 安卓安装与离线使用（PWA）

1. 执行 `pnpm build`，将 `dist/` 内的全部文件部署到支持 **HTTPS** 的静态网站；保留 `sw.js`、manifest 和 icons，建议 `sw.js` 使用 `Cache-Control: no-cache`。
2. 安卓手机用 Chrome 打开 HTTPS 网站，等待首次页面加载完成，在浏览器菜单中选择「添加到主屏幕」→「安装」（名称可能因浏览器版本而异）。
3. 首次打开时保持联网，等待离线资源缓存完成；然后开启飞行模式，从桌面图标重新打开，确认可以练习和播放声音。以后使用无需电脑在线。

离线缓存仅在生产构建启用，`pnpm dev` 不启用。`pnpm preview` 可用于电脑 localhost 上的验证；手机访问 `http://电脑IP:4173` 不具备安装和离线缓存所需的安全环境，必须改用 HTTPS。不要直接用文件管理器打开 `dist/index.html`。

更新网站后，联网打开应用以下载新版缓存，再关闭该网站的所有标签页和应用窗口，重新打开即可使用新版；不会在练习过程中强制刷新。练习记录仍保存在当前网站的本地存储，换域名、清除网站数据或卸载时可能丢失；原局域网地址的记录不会自动转移到新域名。

没有 HTTPS 网站时，也可用安卓 USB 调试进行本地安装验证：电脑安装 Android Platform Tools，连接手机并授权 USB 调试，运行 `pnpm preview`，再在另一个终端运行 `adb reverse tcp:4173 tcp:4173`。手机 Chrome 打开 `http://localhost:4173` 并安装；确认缓存后即可断开 USB。这个地址适合自用验证，后续更新仍需重新连接电脑。

安装环境依据：[MDN：Making PWAs installable](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

## 功能

总览与揭晓答案均并列展示第五、六弦根音在第 0–12 品内的基础按法，包含空弦和第 12 品的同名根音，并可分别试听。例如 Em 显示第五弦第 7 品、第六弦空弦、第六弦第 12 品三种按法；「本组选用」标记保留当前练习路线。

新增「实琴和弦」专题：支持 12 个大调，一组固定一个调和一套第五 / 六弦根音指法。推荐方案综合低品位、根音分布与常见进行的移动距离，总览中可替换单个和弦按法并保存偏好。先看七个顺阶三和弦的指法，再随机覆盖全部七个级数，接着练 I–IV–V–I、I–V–vi–IV、ii–V–I，最后复练卡点。提示分和弦性质、名称、根音位置三步；核对后自行标记「顺利 / 想了一会 / 没按出来」。第 vii° 级提供减三和弦指法，不替换为减七和弦。指法图标记手指、根音、空弦、消音和横按，揭晓后可听按法实际发出的构成音。空格揭晓，数字 1 / 2 / 3 自评（焦点在按钮或表单控件时保留控件自身行为）。通过 `?practice=guitar-chords` 可直接进入；最近 500 次自评和指法偏好独立保存在 `notera.guitar-chords.v1`，不计入自动判分的正确率。刷新或切换专题后重新从总览开始，记录仍保留。下文的十题制与重置恢复适用于原有乐理题型，实琴记录单独保存。

应用打开后直接进入乐理练习，默认选中「音程推算 → 判断音程」。

- **音程推算**：「判断音程」保留先选度数、再选性质的流程；「推算音名」给出起点、上下行方向及完整音程，回答目标音名，按拼写判分。支持自然音与升降音两档。
- **指板定位**：按「弦间音程 → 同音搬运 → 认音 → 找音接力」排列四个独立题型，进入时默认打开弦间音程，每轮 10 题。弦间音程以标准调弦、同品位为前提，覆盖任意两根弦的 30 种有向组合，每轮粗弦到细弦、细弦到粗弦各 5 题，不重复弦对；指板画出六根弦及同品位的起点、终点与方向；左侧弦号旁可显示标准调弦的空弦音名，可开关并记住偏好；性质和度数分两排点选，先选哪排都可以，选齐立即判分，以起点为 1，统一向上循环判断一至七度的音名关系，忽略实际音高方向和八度差（B → D 答小三度，D → B 答大六度，同音名按纯一度处理）；指板箭头只表示位置方向。答后显示音名与向上循环的半音距离；新规则单独统计正确率、正确题平均反应、弦间方向进度、易错弦对与历史，旧规则记录仍保留原判分，最近记录最多保存 100 题。认音只给出一个参照 1，随机高亮一个位置，直接选择它的级数；找音接力从任意非 1 级数起步，指定目标弦并点击目标音，找对的位置成为下一题的参照，本轮调性保持不变。题目在六根弦、随机五品窗口内生成，使用普通品号，不标出根音所在品，不展开整张答案图。提供自然级数和全部半音两档，变化级数统一记作 ♭2、♭3、♯4、♭6、♭7。只记录首次作答；找错后需纠正，或显示单个目标位置再点击后继续，修正不重复计分。各题型与难度分别保存最近 100 题的正确率、正确题平均反应、易错级数和历史；切到后台暂停计时，反馈阅读时间不计入下一题。原来的单点及整图默写记录继续保留，但不并入新的定位统计。
- **同音搬运**：已知一个位置的音名，在指定目标弦点击同音名位置（允许相差八度）。分基础形状（±2 品）、加入二弦偏移（±3 品）、混合巩固（加入六弦与一弦同品位）三阶段，每阶段先看不计分示范。每轮 10 题，两个移动方向各 5 题；第 1–12 品内随机五品窗口，只显示起点，答后展示路径、品位偏移与半音原理。可用提示；首次答错后须纠正，也可显示答案后点击正确位置继续，修正不重复计分。每阶段独立保留最近 100 题，统计独立首次正确率、独立答对平均反应、提示题数及易错弦对，并支持重置恢复。
- **和弦对应**：先覆盖 C 大调 C、Dm、Em、F、G、Am、Bdim 七个顺阶三和弦。「级数与和弦」双向互认罗马级数与和弦名；「和弦名 → 构成音」使用简谱 1–7（1=C）选择三个音，选择顺序不限；「构成音 → 和弦名」从每组三个音的六种排列中随机出题，首音不一定是根音，例如 4·6·1、1·4·6、1·6·4 都对应 F。两个方向独立统计成绩及错题。旧的双向混练统计继续保留，旧错题按方向归入对应题型。解析区分以 C 为 1 的简谱和以和弦根音为 1 的构成公式。
- **独立练习**：各题型分别练习，每轮 10 题，不跨题型出题。认音不会切换到找音；找音接力只连接同一轮的位置；和弦名推构成音与构成音认和弦名分开练，正向题先覆盖七个和弦，再随机重复三个，避免连续重复。音名上下行与「级数与和弦」的正反问法在各自题型内交替出现。
- **分项进度**：普通题型分别记录正确率、用时和题数；指板定位按题型和难度单独记录，平均反应只统计首次答对的题，侧栏统计对应当前练习。
- **题目显示**：音程判断与音名推算题支持音名、简谱、唱名、钢琴键盘四种形式随时切换，保留当前题目和已选答案，并记住显示偏好。
- **声音**：通过 Web Audio 合成音色。音名推算提交前只播放起点音，提交后可听完整答案；和弦题提交前仅在题目已给出音名时提供试听。第一次播放需要用户点击。
- **错题复习**：普通题型只复习当前题型，每轮最多复习 10 道已保存错题；独立答对后移出错题，使用提示答对则保留。
- **本地记录**：使用浏览器 localStorage，保留累计统计、最近练习和错题，支持重置及恢复上次记录。沿用 `notera-progress-v1`、`notera-progress-backup` 存储键，现有记录自动归入「判断音程」，新增题型与旧记录一起保存；重置和恢复覆盖全部题型。

刷新页面会开启新一轮练习，累计统计和错题仍然保留。将浏览器标签隐藏时，作答计时暂停。

简谱与唱名统一使用 **1=C、固定 Do**：C 对应 1 / Do，C4 为不带点的中音，低、高八度分别在下方、上方加点。题目保留原始音名拼写，例如 F♯ 为 ♯4 / ♯Fa，G♭ 为 ♭5 / ♭Sol；琴键显示也提示升降音的拼写，以便判断音程度数。

安装依赖后无需联网即可使用。练习覆盖一至八度的纯、大、小、增、减音程。

## 常用命令

```sh
pnpm dev          # 开发服务器与热更新
pnpm typecheck    # TypeScript 严格类型检查
pnpm test         # 算法、练习状态、存储兼容与组件交互测试
pnpm test:watch   # 开发时持续运行测试
pnpm build        # 类型检查并构建到 dist/
pnpm preview      # 本机和局域网预览生产构建（4173 端口）
pnpm format       # 格式化代码与文档
```

## 快捷键

音程判断题用 1–8 选择度数；「和弦名 → 构成音」用 1–7 选择对应简谱音，再按同一数字取消，最多选三个；和弦名与罗马级数选项使用点击选择，不提供数字快捷键。Space 播放当前允许试听的音；Enter 提交或进入下一题。弦间音程分两排点选性质与度数，选齐立即判分；指板认音可用 1–7 直接回答自然级数；找音在指定弦点击位置，找对后可用 Enter 继续（焦点不在按钮上时）。

## 代码结构

```text
src/
  App.tsx                  应用入口与题目显示偏好
  main.tsx                 React 入口
  styles.css               响应式界面
  pages/PracticePage.tsx    专题切换、练习与分项进度
  components/              题目显示、作答与反馈
  hooks/useAudio.ts        Web Audio 生命周期
  hooks/usePractice.ts     练习状态、记录保存与计时
  lib/notation.ts          四种表示形式、简谱与固定唱名
  lib/theory.ts            音名、半音、音程计算
  lib/exercises.ts         音名推算与和弦题库
  lib/stringIntervals.ts   弦间音名关系、双向弦对出题与独立记录
  lib/fretboard.ts         指板随机出题、接力关系、判分与定位记录
  lib/sameNote.ts          同音搬运形状、分阶段出题、校验与独立记录
  lib/fretboardMemory.ts   旧整图默写记录兼容
  lib/practice.ts          独立题型队列与纯函数状态机
  lib/progress.ts          旧记录读取、校验与存储
  lib/types.ts             领域类型
tests/                     乐理、练习与 React 回归测试
```

UI 使用 JSX 和 React 状态更新，不通过 `innerHTML` 或全局 DOM 事件委托绘制页面。选择答案不会重新挂载按钮或练习区域。

乐理参考：[Music Theory for the 21st-Century Classroom](https://musictheory.pugetsound.edu/mt21c/AugmentedAndDiminishedIntervals.html)。
