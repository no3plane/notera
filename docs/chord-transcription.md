# 扒歌

从练习专题栏的「扒歌」进入，也可以打开 `?practice=transcription`。页面先显示工程列表。打开本地歌曲或选择一个工程后，可以循环听需要的片段，把自己判断出的和弦写进谱面。

## 播放与填写

- 导入浏览器可解码的音频，例如 MP3、WAV 或 M4A。歌曲信息、速度、BPM 和拍号显示在顶部，波形可以点击定位和缩放。速度范围为 0.5×–1.5×，播放时保留音高。
- 谱面初始为空白，一格对应一个拍点。点格子会跳到该拍并可直接输入，当前播放拍以浅绿色显示。和弦名与罗马数字都按原样保存，例如 `Cmaj7`、`G/B`、`iiø7`。
- 方向键按谱面位置移动，Enter 跳到下一拍，Delete 清空当前格。和弦格内和普通页面内容都支持用空格播放或暂停。
- 点小节标题选中一小节，按住 Shift 点第二个小节标题可选连续多小节。触屏可先点「扩选」，再点范围另一端。「循环所选」从选段首拍开始播放，在选段后的第一拍回跳，最后一小节以音频结尾为边界。手动跳到循环外时会退出循环。

## 节拍校准

- Music Tempo 在本地 Web Worker 中分析解码后的音频，返回逐拍时间戳和估计 BPM。谱面、波形标记和播放高亮使用同一份时间戳。若检测不到可用拍点，可以重新检测或换一段音频。
- 拍号默认 4/4，可换成 2/4、3/4、5/4 或 6/8。6/8 按两大拍分组，每格一大拍。设置第 1 小节首拍后，前面仍可填写，最前方的不足小节标为「弱起」。
- 打开「校准节拍」，在谱面选中一拍，再点「设该拍为起点」，即可把它设为第 1 小节首拍。
- 和弦文字跟随拍点。改变拍号或重定小节首拍后，可以在重新划分的谱面上继续填写。
- 如果软件把每拍数成了两拍，打开「校准节拍 → 节拍减半」。预览会隔拍保留已有时间戳，波形、谱面和播放高亮会一起更新。有手动标记的首拍时，预览默认保留它。「试听两小节」从选段或播放头所在小节开始循环，可点「换另一组」比较两种对齐方式。
- 橙色虚线标出即将移除且写有和弦的拍点。逐条选择移动到相邻空拍或从谱面移除，处理完才能应用。节拍和 BPM 在应用时保存。应用提示中的「撤销节拍减半」可用到下次设定起点之前，之后填写在保留拍上的和弦也会保留。

## 工程文件

- 「工程文件」列表显示歌名、原文件名和文件关联状态，并提供「打开新歌」和「导入工程」。在工作区可以查看和修改和弦、导出当前工程或返回工程列表。谱面和原文件信息自动保存在浏览器的 IndexedDB。
- 在支持本地文件访问的浏览器中选歌后，Notera 会记住文件。重新打开工程时，有读取权限即可直接加载原音频。浏览器需要确认时，点击「播放」即可授权。
- 找不到原文件、浏览器拒绝授权，或浏览器不支持记住文件时，播放器会显示「选择上次用的」和原文件名。选回原音频或含该音频的 `.notera` 工程，即可从原位置继续听。
- 每条记录右侧的「删除」会先请你确认。确认后会清理该记录在浏览器里的数据。设备上的原文件可以继续使用。
- 工程保留拍点、和弦、拍号、首拍、速度与上次暂停或定位的位置。选段和波形缩放在当次打开时使用。
- 「导出当前工程」生成 `.notera` 文件。当前已打开的音频会随谱面导出。音频不可用时，导出的文件只包含谱面。两种文件均可在另一台设备导入。
- 播放和波形由 WaveSurfer.js 管理。工作区按需加载，静态 PWA 安装后可离线打开。音频由浏览器本地读取。

## 验收

1. 导入一首真实歌曲，查看波形、检测出的 BPM 与逐拍时间戳，并确认每个和弦格都是空的。
2. 选定副歌里的两小节，保调降速播放。确认播放头回到选段开头，格子按源音频时间依次高亮。
3. 填写 `Cmaj7` 和 `iiø7`，用方向键在格间跳转。改动拍号和小节首拍，检查已填写的和弦在新谱面中仍对应原拍点。
4. 刷新后确认先显示工程列表，点选已保存的工程后可继续填写。验证浏览器能在权限有效时读回原歌曲，需要时也能从播放器授权或重选。导出工程后验证可重新导入。
